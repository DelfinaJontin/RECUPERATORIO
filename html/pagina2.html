Repositorio de obras

Explicacion El sistema gestiona un repositorio de las obras de Laurie Anderson. Primero completa los datos generales, despues, pones las obras, una por una. Cuando las hayas cargado todas, va a apaerecer un boton para calcular el resultado. Una vez que hayas terminado, podes utilizar el boton de "REINICIAR" para volver a empezar.
